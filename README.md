# Retro Battle

A small multiplayer C++ game inspired by the look and social experience of
early handheld RPGs.

Players explore a shared pixel-art world, meet other connected players and
challenge them to multiplayer games.

The first game mode will be a turn-based creature battle system.

## Goals

- Practise modern C++
- Learn client/server networking with Boost.Asio
- Build a small authoritative multiplayer server
- Create a retro 2D game with raylib
- Support Linux and Windows
- Practise disciplined Git and GitHub workflows

## Status

Early development.

## Planned stack

- C++20
- CMake
- Ninja
- vcpkg
- raylib
- Boost.Asio
- Catch2
- nlohmann/json
- SQLite
